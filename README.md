# Dataset YOLO

El dataset utilizado para el entrenamiento y validación de los modelos se puede descargar desde Roboflow:

https://universe.roboflow.com/sekant/my-first-project-4wl7u/dataset/1

Cada colaborador debe descargarlo y ubicarlo en la carpeta `dataset_yolov8/` en su entorno local.

> **Nota:** El dataset ya no se almacena en el repositorio. Está incluido en el `.gitignore` para evitar subir archivos pesados y redundantes.
